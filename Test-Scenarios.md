# E-Commerce Website – Test Scenarios

## Project Overview
This project focuses on manual testing of an e-commerce website.

## Test Scenarios

| Scenario ID | Test Scenario | Expected Result |
|---|---|---|
| TS01 | Verify user login with valid details | User should log in successfully |
| TS02 | Verify login with invalid details | Error message should be displayed |
| TS03 | Verify product search | Relevant products should be displayed |
| TS04 | Verify adding a product to cart | Product should be added to cart |
| TS05 | Verify removing a product from cart | Product should be removed |
| TS06 | Verify quantity update | Cart quantity should be updated |
| TS07 | Verify checkout page | Checkout details should be displayed |

## Testing Type
- Manual Testing
- Functional Testing
- Positive Testing
- Negative Testing
