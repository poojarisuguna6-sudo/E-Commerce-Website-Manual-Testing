# E-Commerce Website Manual Testing

## Project Overview
This is a beginner-level manual testing project based on an e-commerce website. The purpose is to understand and test basic shopping website features.

## Project Objectives
- Understand manual testing concepts.
- Prepare test scenarios and test cases.
- Check website functionality.
- Learn how to report bugs.

## Modules Covered
1. User Login
2. Product Search
3. Add to Cart
4. Remove from Cart
5. Checkout

## Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
